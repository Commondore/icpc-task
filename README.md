# Экзамен Frontend Разработчик - BrewPass

## Описание

Вам предстоит доработать landing page для приложения BrewPass - сервиса доставки кофе. Проект содержит намеренные ошибки и недоработки, которые необходимо исправить.
Изображение макет как он должен выглядеть лежит в папке `public/mockup.png`

## Время выполнения: 2,5 часа

## Начало работы

1. Склонируйте репозиторий
2. Переключитесь на свою ветку: `task-[ваш_номер]`
3. Установите зависимости
4. Запустите проект

## Критерии оценивания и задания

### 1. Работа с Git (20 баллов)

**Что нужно сделать:**

- Корректно склонировать репозиторий
- Переключиться на нужную ветку
- После выполнения каждого критерия делать коммит с осмысленным сообщением
- Итого должно быть минимум 7 коммитов

**Формат коммитов:**

- `fix: описание того что исправили`
- `feat: описание того что добавили`

### 2. HTML структура и семантика (20 баллов)

**Проблемы в коде:**

- Используются `div` вместо семантических тегов
- Неправильная иерархия заголовков (h1, h2, h3 используются не по порядку)
- Отсутствует семантический тег для описания героя (должен быть `p`)
- Карточки features должны быть в списке

**Что нужно исправить:**

- Заменить все `div` на правильные семантические теги
- Исправить иерархию заголовков (h1 только один на странице, далее h2, h3...)
- Добавить семантические теги где необходимо
- Добавить изображение телефона в hero секцию из папки `public/img/phone.png`

### 3. Верстка и Layout (15 баллов)

**Проблемы в коде:**

- Header не закреплен вверху страницы
- Неправильные отступы в hero секции
- Сломана сетка в features секции
- Отсутствует background image в hero секции

**Что нужно исправить:**

- Закрепить header в верхней части страницы
- Исправить отступы и выравнивание
- Восстановить правильную сетку features
- Добавить фоновое изображение в hero секцию

### 4. Адаптивность (15 баллов)

**Что нужно проверить и исправить:**

- Корректное отображение на мобильных устройствах (320px-767px)
- Планшетная версия (768px-1023px)
- Десктопная версия (1024px+)
- Мобильное меню должно работать корректно
- Кнопки и текст должны быть читаемыми на всех разрешениях
- Решить проблему с карточками при мобильных устройствах

### 5. Бизнес логика React (20 баллов)

**Что нужно добавить:**

- Состояние для отслеживания кликов по кнопке "Get Started Now"
- Счетчик загрузок, который отображается после первого клика в формате "Downloaded 1 time"
- Модальное окно с формой при клике на "Watch Demo"
- Переключение темы (светлая/темная) через кнопку в header
- Анимация floating bubbles (должны медленно двигаться)

### 6. Архитектура и компонентизация (10 баллов)

**Что нужно сделать:**

- Разбить монолитный компонент на логические части
- Создать папку `components` и поместить туда все компоненты
- Правильно передавать props между компонентами
- Использовать современные React хуки

## Дополнительные требования

- Код должен быть читаемым и содержать комментарии где необходимо
- Использовать современные возможности React (хуки, функциональные компоненты)
- Следовать принципам чистого кода
- Все функции должны работать корректно
- Обработка ошибок где это необходимо
