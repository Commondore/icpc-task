# Экзамен Frontend Разработчик - FoodieDelivery

## Описание

Вам предстоит доработать landing page сервиса доставки еды FoodieDelivery. Проект содержит намеренные ошибки и недоработки, которые необходимо исправить.

## Время выполнения: 2 часа

## Критерии оценивания и задания

### 1. HTML структура и семантика (20 баллов)

**Проблемы в коде:**

- Используются `div` вместо `nav` в навигации
- Неправильная иерархия заголовков (h3 в hero секции)
- Для меню категорий используются div вместо списков

**Что нужно исправить:**

- Заменить div на nav в навигации
- Исправить иерархию заголовков
- Использовать ul/li для категорий блюд

### 2. Верстка и Layout (15 баллов)

**Проблемы в коде:**

- Навигация в header не выровнена
- Неправильные отступы между элементами
- Hero секция использует flex вместо grid

**Что нужно исправить:**

- Исправить выравнивание в навигации
- Восстановить правильные отступы
- Использовать grid для hero секции

### 3. Адаптивность (15 баллов)

**Что нужно сделать:**

- Добавить медиа-запросы для всех разрешений
- Сделать адаптивное меню для мобильных устройств
- Исправить сетку категорий блюд на малых экранах

### 4. React логика (20 баллов)

**Что нужно добавить:**

- При вводе данных страны в поле поиска, вывести информацию о стране:
  - Страна
  - Столица
  - Количество населения
  - И снизу вывести информацию что доставка в этму область времено не работает
  - Можете использовать restcountries rest api для запроса страны
  - Используйте модальное окно для вывода информации
- Модальное окно при клике на блюдо с его инфмормацией

### 5. Компонентизация (10 баллов)

**Что нужно сделать:**

- Разбить на компоненты (Header, Hero, Categories и т.д.)
- Правильно организовать папки
- Использовать пропсы и хуки

## Дополнительные требования

- Код должен быть читаемым
- Использовать современные возможности React
- Следовать принципам чистого кода
