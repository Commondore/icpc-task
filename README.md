# Экзамен Frontend Разработчик - SEEDRA

## Описание

Вам предстоит доработать магазин продажи семян SEEDRA. Проект содержит намеренные ошибки и недоработки, которые необходимо исправить.

## Время выполнения: 2 часа

1. Склонируйте репозиторий
2. Переключитесь на свою ветку: `task-[ваш_номер]`
3. Установите зависимости
4. Запустите проект

## Критерии оценивания и задания

### 1. Работа с Git (20 баллов)

**Что нужно сделать:**

- Корректно склонировать репозиторий
- Переключиться на нужную ветку
- После выполнения каждого критерия делать коммит с осмысленным сообщением
- Итого должно быть минимум 6 коммитов

**Формат коммитов:**

- `fix: описание того что исправили`
- `feat: описание того что добавили`

### 2. HTML структура и семантика (20 баллов)

**Проблемы в коде:**

- Используются `div` вместо `nav` в навигации
- Неправильная иерархия заголовков (h3 в hero секции)
- Для меню категорий используются div вместо списков

**Что нужно исправить:**

- Заменить div на nav в навигации
- Исправить иерархию заголовков
- Использовать ul/li или article

### 3. Верстка и Layout (15 баллов)

**Проблемы в коде:**

- В шапке есть проблемы с лого, порядком элементов и отступами
- Features сломаны должны быть в колонках
- Сломаны карточки товаров не правильный список

### 4. Адаптивность (15 баллов)

**Что нужно сделать:**

- Добавить медиа-запросы для нужных разрешений
- Сделать адаптивное меню для мобильных устройств
- Исправить сетку с карточками

### 5. Бизнес логика React (20 баллов)

**Что нужно добавить:**

- При нажатии на кнопку "В корзину" или иконку корзины, отображать счетчик с количеством добавленных товаров в шапке
  - При нажатии на иконку показать небольшой список добавленных товаров
- При нажатии на иконку сердечка(избранное) добавить счетчик избранных товаров

### 6. Архитектура и компонентизация (10 баллов)

**Что нужно сделать:**

- Разбить монолитный компонент на логические части
- Создать папку `components` и поместить туда все компоненты
- Правильно передавать props между компонентами
- Использовать современные React хуки

## Дополнительные требования

- Код должен быть читаемым и содержать комментарии где необходимо
- Использовать современные возможности React (хуки, функциональные компоненты)
- Следовать принципам чистого кода
- Все функции должны работать корректно
- Обработка ошибок где это необходимо
